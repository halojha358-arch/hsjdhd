快速上手

  1. 首次打开完成 3 步设置：起床时间、作息类型、昵称。
  2. 在“此刻”页查看今天的精力曲线、睡眠债和今晚建议的入睡时间。
  3. 睡前点“开始入睡”进入床头模式：暗光时钟、伴睡声景、渐进唤醒闹钟。
  4. 醒来点“我醒了”，昨晚会记录到“夜记”。
  5. 在“声景”页叠加雨声、潮汐、炉火等声音，可以单独调音量、定时关闭。

常见问题

提醒没有响？

请在 iPhone 的“设置 → 通知 → 深眠时光”中允许通知，并检查专注模式是否屏蔽了本应用。提醒时间可以在“我的 → 提醒”中调整。

锁屏后声景停止了？

声景支持锁屏后继续播放。如果被来电或其他应用的声音打断，回到“声景”页重新点播放即可；也请确认没有设置定时关闭。

我的数据保存在哪里？会上传吗？

睡眠记录、照片和设置只保存在你的手机上。只有你主动提交意见反馈，或在“云端备份”中配置了自己的服务器并上传时，相应内容才会离开手机。详见隐私政策。

换手机时怎么迁移数据？

在旧手机“我的 → 本地数据 → 导出完整备份”，把 JSON 文件存到“文件”或发给自己；在新手机“我的 → 本地数据 → 恢复”中选择这个文件。

怎么删除全部数据？

在“我的 → 本地数据 → 清空全部数据”中确认两次即可删除，删除后无法恢复。也可以直接删除本应用。

精力曲线是怎么算的？

参考睡眠研究中的“双过程模型”，根据你的起床时间、近期睡眠债和作息类型，估算一天中的高峰和低谷。结果仅供参考，不能替代医疗诊断。

开启隐私锁后面容 ID 识别失败？

可以改用设备密码解锁。如需关闭隐私锁，在“我的 → 隐私锁”中验证身份后关闭。

怎么给某一晚添加照片？

在“夜记”中打开那一晚进行编辑，点“照片”，选择拍照或从相册选择。长按照片可以移除。
